# 已知限制

按「影响可用性」排序。这些不是遗漏，是刻意搁置或当前版本砍掉的。

## 引擎能力

| 缺什么 | 影响 | 原因 |
|---|---|---|
| `webView` / `webJs` | 需过 Cloudflare 的源不可用 | 原版靠 WebView 执行 JS，Android 上有，但这个项目没接 |
| `Packages.*` | 约 1/60 源不可用（样本里 1 条用 `javax.crypto`） | 安全策略：能让脚本拿到任意 Java 类 |
| `startBrowser` / 验证码 | 需要人机交互的源不可用 | 无 UI 交互设计 |
| 图片型书源渲染 | 图片列表已抓到，UI 只列 URL | 未接图片加载库 |

## 功能

| 缺什么 | 说明 |
|---|---|
| **书源规则编辑** | 只能导入 / 删除 / 启停，不能改规则。改书源必须重新导入整个 JSON |
| **书架 UI** | 阅读进度写进 `progress.json`，但没有「打开书跳回上次位置」 |
| 阅读设置 | 字号 / 行距 / 背景色 / 翻页模式都没有 |
| 目录搜索 | 421 章的目录只能硬滚 |
| 跨源聚合的源切换 | 搜索已按「书名+作者」聚合，但只打开第一个源 |
| 封面图 | `coverUrl` 已抓，UI 不显示 |
| MOD 单独禁用 | 只能删目录 |
| URL 订阅书源 | 只支持文件 / 粘贴 |
| 深色模式手动切换 | 只跟随系统 |
| 定时巡检 | 只有手动「全部重测」 |
| 搜索并发 | 串行。方案允许 4 并发（不同域名） |

## 工程债

| 项 | 现状 |
|---|---|
| 持久化 | JSON 文件，不是 SQLite。结构已按可迁移设计 |
| 网络库 | `HttpURLConnection`，不是 OkHttp。没有 Cookie 分桶、TLS 配置、EventListener 计时 |
| 正则超时 | 只能丢线程，不能真中断（`java.util.regex.Pattern` 没有可挂 hook 的计数器） |
| fixture 回归池 | 没有。目前测试是 81 个单元测试 + 1 条真实联网端到端 |
| 签名 | release 用 debug key |
| minSdk | 26（Android 8.0），未在低于 API 36 的设备上验证 |
| ProGuard / R8 | 全关 |

## 未实现的设计部分

原始设计还包含服务器 / NAS 书库 / Web 端 / 登录 / 同步 / 跨源分类聚合。
