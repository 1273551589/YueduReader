## ⚠️ 从 0.3.6 升级必读

**0.3.6 会在读取旧体检记录时崩溃**（`NullPointerException`），0.3.7 已修复。直接覆盖安装即可，数据不用动。

---

## 修复：旧格式文件导致的崩溃

v0.3.6 把体检结果改成扁平 DTO 存储（因为 `RuleError` 是 sealed class，Gson 无法还原），但 `kind` 字段声明成了非空 `String`：

```kotlin
data class RuleErrorSnapshot(
    val kind: String,        // ← Gson 会绕过 Kotlin 空检查塞 null
```

旧格式文件里 `error` 是 `{"stage":"toc.chapterList"}`，**没有 `kind` 字段**。读回来时 `kind = null`，而 `when(kind)` 有 12 个字符串分支会调 `kind.hashCode()`：

```
java.lang.NullPointerException: Cannot invoke "String.hashCode()" because "<local1>" is null
    at RuleErrorSnapshot.toRuleError(RuleError.kt:113)
    at PersistedCheckResult.toResult(Repository.kt:256)
```

**触发条件**：机器上存在任何一条带 `error` 的旧体检记录。正常使用过的都会踩到。

修复：`kind` 改为 `String?`，`PersistedWarning.kind` 同理。

> 这个 bug **编译器也能挡住**：改回非空 `String` 会在 `Repository.kt:276` 报类型不匹配。

## 新增：旧格式兼容测试（4 条）

之前只测了「新格式写 + 新格式读」，没测「**旧格式读**」——而后者才是升级用户的真实场景。

| 用例 | 抓什么 |
|---|---|
| 旧格式全正常也能读 | 基本可用性 |
| **旧格式有一条带 error 时其他源不能丢** | 直接抓出上面的 NPE |
| 新格式往返不丢字段 | 含警告里的规则串要能还原 |
| 空文件 / 非 JSON 返回空而不是崩 | 容错 |
