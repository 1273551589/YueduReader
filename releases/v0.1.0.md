## 首个可用版本

一个能装、能搜、能读的 Android 阅读器，按 Legado 书源规则语义**自己实现**（不依赖原版源码）。

## 做了什么

| 模块 | 内容 |
|---|---|
| 规则引擎 | `&&` `\|\|` 组合、`##正则##`、`@put/@get`、`{{}}` 插值、CSS / JSON path / XPath |
| 抓取流水线 | 搜索 → 详情 → 目录 → 正文，**阶段级实例隔离**（规避上游 `isRegex` 不复位的缺陷） |
| 书源导入 | 数组 / 单对象 / 分组对象三种形态，按 `bookSourceUrl` 去重，坏条目单独列出 |
| 体检 | 一次抽样 / 六个 UI 状态 / 总耗时 / 卡在哪一步 |
| MOD | 声明式（theme / sources / categories），**零代码执行** |
| UI | Compose：书架 / 搜索 / 详情 / 阅读 / 书源 / MOD |

## 已验证的书源

**SF轻小说**（非 R18）。选它的原因：`linovelib` 搜索必过人机验证码，`wenku8` 返回 403，`linovel.net` 连不上，SF 是唯一能直接解析的。

实测《Sword Art Online刀剑神域》：搜索 26 条 → 详情（天闻角川 / 游戏 / 369万字）→ 目录 421 章 → 正文 409 字。

## 已知缺口

- **`@js` 脚本规则不支持**（覆盖 24% 的源），命中时显式返回 `UnsupportedApi`，不静默失败
- 目录 / 正文分页未实现
- 书架 UI 是占位，阅读位置只写不读
- 持久化用 JSON 文件，不是 SQLite
