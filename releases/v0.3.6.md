## 修复：体检结果重启后全部丢失（严重）

`CheckResult.error` 是 sealed class。Gson 反序列化时遇到抽象类型直接抛异常，**整个 Map 变成 null**。

```
两条结果（一条带 error，一条 READABLE）
→ 读回来 ok=false, val=null
→ "可读"那条也跟着没了
```

用户看到的就是：体检完显示「抽样可读」，**重启后全变回「未验证」**。

修复：把 `RuleError` 摊平成可还原的 `RuleErrorSnapshot`（`kind` / `arg` / `code`），读回来再拼。

## 修复：正则写错是静默失败

```
##(unclosed##X  → 返回原文，lastError=null   ← 用户以为"没匹配上"
##zzz##X        → 返回原文，lastError=null   ← 真的没匹配上
```

两种表现**完全一样**，而写错正则恰好是书源作者最常踩的坑。

修复：正则编译失败记 `RuleSyntaxError`。

## 修复：警告被冲掉

一个搜索阶段跑 26 条 × 9 个字段，**最后一次成功就把前面所有错误痕迹冲没了**（`lastError` 每次调用开头清空）。

改成**出错当下回调**（`onRuleError`）。

## ⚠️ 本版会崩（0.3.7 修复）

新 DTO 的 `kind` 声明成非空 `String`，而 **Gson 会绕过 Kotlin 空检查塞 null**。旧格式文件没有 `kind` 字段 → `when(kind)` 调 `hashCode()` → NPE。
