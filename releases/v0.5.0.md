## 底部 5 Tab

`书架` · `书城` · `Pixiv` · `搜索` · `设置`

- **书架**：入口卡片 + **最近阅读列表**（真实的阅读进度，不再是占位文字）
  - 时间显示「刚刚 / 3 小时前 / 11-26」，点进去直接跳回上次读到的那一章
- **书城**：跨源聚合（见下）
- **Pixiv**：框架就位，网络层 v0.7.0 接
- **搜索**：跨源搜索（从书架搬过来，成为一级页面）
- **设置**：所有全局配置收口

导航实现上的一个决定：**一个 NavHost + 条件显示底栏**，而不是「每个 Tab 一个 NavHost」。

理由是详情/阅读/书源管理/MOD 都是「从某个 Tab 推出去」的页面，
多 NavHost 会让返回栈和状态管理炸开。现在底栏只在 `home` 路由显示，
其余路由全屏，返回栈天然正确。

用 `rememberSaveable` 存当前 Tab —— 转到详情页再返回，回到的还是原来那个 Tab。

## 书城聚合页

### 数据来源：只聚合通过体检的源

`BookstoreEngine.usableSources()` 只收 `READABLE` 的源。

这是刻意的：未通过四段校验的源塞进书城，用户点进去就是空的，
**体验比没有还差**。宁可书城只有 2 个源，也不要 20 个源一半打不开。

### 四层筛选 + 排序

| 排 | 内容 |
|---|---|
| 1 | 主分类：全部 / 玄幻奇幻 / 武侠仙侠 / 都市言情 / 科幻末世 / 悬疑灵异 / 历史军事 / 轻小说 / 游戏竞技 / 其他 |
| 2 | R18 细分（**仅开关打开时出现**）：不限 / 母子 / 校园纯爱 / NTR / 百合 / 调教 / 人妻熟女 |
| 3 | 内容分级：全部 / 全年龄 / 成人向（**未开 R18 时只有前两个**） |
| 4 | 书源：全部书源 + 各个可读源胶囊（只有 1 个源时不显示） |

排序：综合默认 / 近期更新 / 字数倒序 / 字数正序。

字数解析要能吃野格式 —— 书源给的是 `1234567`、`120万`、`300万字`、`12千字`、
`1亿`、`连载中`（非数字）。解析不出来返回 -1，排序时沉底。

### 渐进式加载

一次性全量爬会：① 把流量烧光 ② 触发目标站封禁 ③ 首屏等 30 秒。

所以：
- **首屏**：每个源并发拉第 1 页
- **翻页**：滚到倒数第 6 个才开始拉下一页（用户看不到加载停顿）
- **限流**：按域名做并发闸门，同域名最多 2 并发，跨域名才并行
- **上限**：单源最多 6 页，防止用户一直滚把站爬穿

跨源去重按「书名 + 作者」，保留首次出现的那条（先到的源往往封面/简介更完整）。

## R18：硬过滤，不是隐藏入口

这是 v0.5.0 最关键的一条设计。

**漏一本的代价是「用户没开 R18 也看到了」，这是产品事故。
误判成人的代价只是少显示一本。**

所以过滤做在**三个层次**：

1. **加载时**（`BookstoreEngine.fetchOne`）：`!adultOn && cls.isAdult` → 直接不进结果集
2. **筛选时**（`BookstoreState.visible`）：再挡一次，防止「设置加载后才关掉开关」
3. **判定时**（`BookClassifier`）：书源分组或 kind 带 `R18/成人/18禁/情色` 标记 →
   **整源强制标成人**，哪怕书名简介完全干净

第 2 层看起来冗余，但它是必要的 —— `SharedPreferences` 是异步加载的，
首屏加载时开关可能还是默认的 `false`，之后才读到用户设置。

`SettingsVisibilityTest` 把整个真值表逐条锁死（开关 × 分级 × 是否成人 = 12 种组合）。

## 智能分类引擎校准

`BookClassifier` 在 v0.4.0 就有了，这一版用**真机上书城的真实数据**校准了一轮。

真机截图暴露三个问题：

| 书 | 之前判成 | 应该是 | 原因 |
|---|---|---|---|
| Sword Art Online刀剑神域 | 玄幻奇幻 | 游戏竞技 | 「SAO」「死亡游戏」没在词库里 |
| 我转生就超神 | 轻小说 | 游戏竞技 | 「虚拟实境」没在词库里 |
| 圣女怎么可能是男孩子 | 其他 | 轻小说 | 「圣女」「教皇」没在词库里 |

修法不是加 `if`，而是**补词库** —— 规则库是数据不是代码：

- 游戏竞技补 20+ 词：`虚拟实境` / `vr游戏` / `全息游戏` / `死亡游戏` / `登出` /
  `刷怪` / `任务面板` / `刀剑神域` / `sao` / `通关` / `超神` …
- 轻小说补日系叙事词：`物语` / `恋爱物语` / `同居` / `教皇` / `圣女` / `棋手` / `日常`

`ClassifierRealCasesTest`（7 条）把这些真实书目锁成回归用例 ——
以后改词库如果把这几个判错了，测试立刻挂。

## 设置中心

以前书源/MOD 管理散落在书架页的入口卡片上，而 R18 / 字号 / 阅读主题**根本没有入口**。

现在收口成 4 个分区：

- **内容安全**：R18 总开关（带说明：关闭时是硬过滤，不只是隐藏入口）
- **书源与 MOD**：显示数量 + 可读数 + 失败数，跳转管理页
- **阅读器**：字号（13–30 sp 步进器）、行距（1.20–2.40 倍）、
  背景主题（日间/护眼/夜间）、翻页方式（滚动/翻页）、自动恢复进度
- **Pixiv**：PHPSESSID / Refresh Token / 代理

⚠️ 修了一个 UI bug：说明文字里写了 `**硬过滤**`，Compose 的 `Text` 不解析 markdown，
星号原样显示出来了。已去掉。

## 已知限制（写出来而不是藏起来）

1. **Pixiv 还没有网络层** —— 页面上明确标注「v0.7.0 交付」并列出要做的事，
   而不是放几个假封面骗点击
2. **书城的源少时内容会重复** —— 同源的翻页靠轮换分类，
   但一个源只有 1~2 个分类时第 2 页会和第 1 页大量重叠（去重后能挡住）
3. **搜索仍是串行** —— 4 并发是方案里的目标，还没做
4. **设置未接线到阅读器** —— 字号/主题已经存下来，但 `ReadScreen` 还没读取
   （v0.6.0 一起做）
